1) Создай репозиторий на github.com и загрузи в него все файлы из этого архива, КРОМЕ build.yml (папки не нужны, все файлы лежат рядом).
2) Вкладка Actions -> "set up a workflow yourself". Откроется редактор. Удали всё в нём и вставь содержимое файла build.yml. Нажми Commit changes.
   (Или: Add file -> Create new file, в имени напиши .github/workflows/build.yml и вставь содержимое.)
3) Сборка пойдёт сама (5-10 минут). Внизу страницы сборки, в Artifacts, скачай:
   RaevYoU-Admin-Windows (.exe) и RaevYoU-Admin-Android (.apk).
